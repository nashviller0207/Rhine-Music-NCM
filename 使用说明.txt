# Rhine Music Desktop 使用说明（0.6.0-dev.92 · 网易云定制版）

## 一、运行环境（别人用需要什么）

- **操作系统**：Windows 10 / 11 x64（不支持 macOS / Linux）。
- **WebView2 Runtime**：需要 Microsoft Edge WebView2 Evergreen Runtime。Windows 11 和已更新的 Windows 10 一般自带；如果启动时提示缺失，去微软官网下载安装一次即可。
- **.NET Framework**：4.6.2 及以上（Windows 10/11 自带 4.8，无需另外安装）。
- **Node.js**：**不需要**。运行所需的 node.exe 已打包在 exe 里，内部音乐服务只监听 127.0.0.1。
- **显卡**：支持 WebGL 2 的显卡（集显也可以）；三维界面帧率取决于显卡、驱动和显示器。
- **磁盘空间**：约 250 MB 起。首次启动会解压约 70–100 MB 程序资源到 %LOCALAPPDATA%\Rhine Music，另外还有曲库索引和封面缓存。
- **目录权限**：普通用户即可。建议放在普通目录（如 D:\RhineMusic）运行，不要放在系统保护目录或受限沙箱目录。
- **网络**：本地曲库播放不需要联网；网易云歌单、在线搜索、封面和歌词需要联网。
- **网易云客户端（可选）**：想用网易云歌单/在线搜索时，需要本机安装并登录网易云音乐客户端（程序只读取本机登录态，不上传账号）。

## 二、怎么用

1. 双击 exe（或桌面快捷方式「Rhine Music」）。
2. 首次启动会解压程序资源到 %LOCALAPPDATA%\Rhine Music\app-v0.6.0-dev.92，需要几秒钟。
3. 打开「音乐库」：会显示本机音乐和网易云账号的收藏/歌单。
4. 搜索：输入关键词 → 按 **Enter** 进入在线单曲架；滚轮选曲，点击或 Enter 打开单曲，右键退出。
5. 专辑详情里点击曲目即可播放；播放时左侧 3D 卡片会显示当前歌曲的封面，歌词面板同步滚动。
6. 操作提示：左右切分类，上下/滚轮切专辑，Enter 打开专辑，Esc / 右键逐级返回。

## 三、数据位置与卸载

- 程序资源：%LOCALAPPDATA%\Rhine Music\app-v<version>
- 曲库索引 / 歌单 / 设置 / 缓存：%LOCALAPPDATA%\Rhine Music\music-data-v3
- 卸载：关闭程序，删除 exe 所在目录和 %LOCALAPPDATA%\Rhine Music 即可。

## 四、常见问题

- **提示缺少 WebView2**：安装 Microsoft Edge WebView2 Evergreen Runtime 后重试。
- **网易云未连接**：确认本机网易云客户端已登录，然后重启本程序。
- **歌曲不能播放/没有声音**：检查网络和账号权益；本地文件被移动时重新扫描曲库。
- **没有封面**：会显示内置默认封面，不影响播放。

## 五、已知限制

- 在线音质为 320 kbps mp3，无损 FLAC 尚未接入。
- 最多显示 24 个网易云歌单（「我喜欢的音乐」优先），可用环境变量 RHINE_NETEASE_MAX_PLAYLISTS 调整。
- 仅复用本机网易云客户端登录态，暂未提供扫码登录。
- 本项目为非官方爱好者作品，音乐、封面与商标版权归相应权利人所有。
