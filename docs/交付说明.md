# Rhine Music Desktop · 双击即用说明（网易云版）

## 一、怎么用

1. 双击桌面快捷方式「Rhine Music」（或 D:\RhineMusic\Rhine-Music-Desktop-0.6.0-dev.60.exe）。
2. 首次启动会把约 70 MB 播放器资源解压到 %LOCALAPPDATA%\Rhine Music\app-v0.6.0-dev.60，需要几秒。
3. 界面里会直接出现你网易云账号的收藏歌单（“我喜欢的音乐”+ 收藏/自建歌单，最多 24 个），点「打开专辑」进歌单，点曲目即可播放，歌词面板同步滚动。

## 二、前置条件

- 本机网易云音乐客户端已登录：本程序复用客户端登录态（只读，不复制、不上传、不打印 cookie）。
- 系统需有 Microsoft Edge WebView2 Runtime（Windows 11 一般自带）。
- 音源权益以你自己账号为准（VIP 曲目按账号权益播放，不做破解/绕过）。

## 三、已知限制（当前版本 0.6.0-dev.60）

| 项 | 现状 |
| --- | --- |
| 音质 | 320 kbps mp3（无损 FLAC 尚未接入） |
| 歌单数量 | 最多 24 个（“我喜欢的音乐”优先）；可用环境变量 RHINE_NETEASE_MAX_PLAYLISTS 调整 |
| 登录方式 | 目前仅“复用网易云客户端登录态”；未登录/未安装客户端时只显示本地曲库 |
| 本地曲库 | 仍可用：在“音乐库”里添加本地文件夹后自动扫描 |
| 主题 | 暖昼 / 薄暮 / 深夜（深夜为暗色） |
| 启动位置 | 请从桌面快捷方式或 D:\RhineMusic 启动；不要从 DSH 工作区目录直接运行（会报访问被拒绝） |

## 四、数据与卸载

- 程序资源：%LOCALAPPDATA%\Rhine Music\app-v0.6.0-dev.60
- 曲库索引/歌单/设置：%LOCALAPPDATA%\Rhine Music\music-data-v3
- 卸载：关掉程序，删除 D:\RhineMusic 和 %LOCALAPPDATA%\Rhine Music 即可。

## 五、合规与风险

- 仅个人自用：不对外分发本程序或修改版；不用于绕过付费/会员/版权限制。
- 登录态来自本机客户端，属协议灰色区域；账号风控风险由使用者自担。
- 网易云接口/客户端升级可能导致登录态或接口失效，届时需要更新程序。

## 六、已验证记录（2026-10-30）

- 桌面 exe 从 D:\RhineMusic 启动成功（窗口 Rhine Music，服务 127.0.0.1:5175）。
- /api/netease/status：loggedIn=true，65 个歌单，来源 local-client-cef。
- /api/library：24 张专辑 / 1261 首曲目（含“我喜欢的音乐”865 首）。
- 在真实桌面窗口内验证：点开专辑 → 点曲目 → 顶部状态变为正在播放，歌词同步滚动。

## 七、开发/重建（可选）

- 源码：D:\DSH creat world\rhine-music\app
- 重建：cd D:\DSH creat world\rhine-music\app；用 Node 24 + npm run build；再执行 scripts/build-windows.ps1 -NodePath <node24> -WebView2Dir sdk/lib -RuntimeTemplateDir D:\DSH creat world\rhine-music\build-rt -OutputDirectory D:\DSH creat world\rhine-music\outputs
- 详细架构与网易云接入说明见 rhine-music/docs/architecture.md、netease-integration.md、p0-server-evidence.md
